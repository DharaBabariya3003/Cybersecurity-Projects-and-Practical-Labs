# Web Application Vulnerability Assessment and Penetration Testing

This project documents a hands-on VAPT exercise conducted in a simulated web application environment using OWASP Juice Shop.

## Environment
- Kali Linux
- Docker
- OWASP Juice Shop

## Tools used
- Burp Suite
- Nmap
- Nikto
- Gobuster
- curl
- SecLists
