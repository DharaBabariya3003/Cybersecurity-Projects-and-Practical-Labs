# Securing the Digital Marketplace: Strengthening Security for Vulnerable Websites

This project focuses on practical application security testing and vulnerability exploitation using the OWASP Juice Shop environment.

## Project Activities

- Reconnaissance and HTTP request analysis using Burp Suite.
- Intercepting and modifying HTTP requests.
- Testing Cross-Site Scripting (XSS).
- Performing SQL injection testing.
- Analysing application endpoints.
- Testing access control and administrative routes.
- Examining directory and sensitive file access vulnerabilities.

## Tools and Environment

- Kali Linux
- Burp Suite
- OWASP Juice Shop
- Nmap (included in the project scope)

## Objective

To gain practical experience in identifying, testing and understanding common web application security vulnerabilities.
